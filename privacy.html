geonwoo-cc Privacy Policy

Effective October 17, 2026 · API client of the YouTube channel “오늘건우 (Onul Geonwoo)”

What geonwoo-cc is

geonwoo-cc is a private command-line tool run only by the owner of the YouTube channel “오늘건우”, a Korean family baby vlog. It is not offered to, sold to, or used by anyone else. It uses the YouTube Data API to add multilingual accessibility to the owner’s own videos: translated closed captions, localized titles and descriptions, and tags.

Data the tool accesses

  • The authenticated owner’s own channel and video information (video IDs, titles, descriptions, tags, caption track list).
  • Caption files and translations that the owner creates for those videos.

It does not access other users’ channels, viewer data, comments, analytics, or any personal information of viewers.

How data is used and stored

  • Data is used only to upload captions and localized metadata to the owner’s own videos.
  • The OAuth token and working files are stored only on the owner’s personal computer. Nothing is stored on any server operated by the tool.
  • No data is sold, shared with, or transferred to third parties.

YouTube and Google

This tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time from the Google Account security settings at security.google.com/settings/security/permissions. When access is revoked, the locally stored token is deleted and no further data is accessed.
